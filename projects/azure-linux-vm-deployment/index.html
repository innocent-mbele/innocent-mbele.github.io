Azure Linux VM Deployment

Ubuntu VM with SSH key authentication hosting a custom Nginx web page.

Overview

An Ubuntu Linux virtual machine was deployed in Azure with SSH key authentication. Nginx was installed and configured to host a custom web page.

Objectives

  • Deploy and access a Linux VM securely and serve web content.

What was done

  • Configured and deployed the VM.
  • Connected over SSH with key-based authentication.
  • Installed Nginx and created a custom page.
