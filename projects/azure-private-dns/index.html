Azure Private DNS

Private DNS zone linked to a virtual network for internal name resolution.

Project overview

An Azure Private DNS zone was created and linked to a virtual network to provide private name resolution for Azure resources without exposing records to the public internet.

Objectives

  • Provide internal-only DNS resolution for a VNet.

Implementation

  • Created the Private DNS zone.
  • Linked the virtual network to the zone.
