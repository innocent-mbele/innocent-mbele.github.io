Network Automation with Python and Netmiko

Inventory-driven Python scripts that connect to a Cisco IOS router with Netmiko, parse output with TextFSM and write a JSON device report.

Overview

Python scripts connect to a Cisco IOS router (R1) with Netmiko, collect show version and show ip interface brief output, parse the interface table with TextFSM and save a structured JSON report. A later version reads connection details from a JSON device inventory. The repository describes a wider plan (Ansible, APIs, NETCONF/RESTCONF); only the Python stage is published so far.

Objectives

  • Collect device information automatically instead of by hand.
  • Drive connections from an inventory file rather than hard-coded hosts.

What was done

  • device_info.py connects to R1, runs show commands and extracts hostname, IOS version, uptime and interfaces.
  • inventory_reader.py and inventory_connection.py load inventory/devices.json and open a Netmiko session.
  • collect_device_info.py combines the inventory with collection and writes api/<hostname>-device-info.json.
