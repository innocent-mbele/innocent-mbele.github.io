Monitor and Maintain Azure

I used the Activity Log to find failed operations, fixed a resource provider that was not registered and found an unused public IP.

Overview

I used Azure Monitor to check what was happening in my subscription. In the Activity Log I filtered the last seven days and looked at the failed operations. One failure came from the Microsoft.RecoveryServices provider, which was not registered. I registered it and checked the result. I also looked into a failed DDoS protection status operation and found a public IP that was not attached to anything. I also explored Azure Monitor Metrics on an existing virtual machine.

What I set out to do

  • Find failed operations in the subscription.
  • Fix the cause and confirm the fix.
  • Find resources that are not in use.

What I did

  • I filtered the subscription Activity Log to the last seven days and reviewed successful and failed operations.
  • I found that Microsoft.RecoveryServices was NotRegistered, which caused a failed backup status operation.
  • I registered the provider at subscription level.
  • I investigated the failed DDoS protection status operation and the PublicIpNotConnectedToBackend error.
  • I found the public IP vnet-eastasia-1-IPv4 (Standard SKU, East Asia) with no backend resource.
  • I explored Azure Monitor Metrics on an existing virtual machine.
