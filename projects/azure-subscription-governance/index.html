Azure Subscription Governance

Azure Policy tag enforcement at resource-group scope plus scheduled VM shutdown with an Azure Automation runbook and managed identity.

Overview

The Azure subscription and resource group configuration were reviewed, and Azure Policy was used to enforce resource tagging. A Require a tag on resources assignment at the rg-rbac-lab scope required the Environment=Lab tag. An Ubuntu VM and its supporting resources were deployed and evaluated for compliance. Automated VM shutdown was then implemented with Azure Automation.

Objectives

  • Enforce a tagging standard on resources with Azure Policy.
  • Verify compliance from the Portal, Azure CLI and PowerShell.
  • Automate VM shutdown on a schedule to control cost.

What was done

  • Inspected subscription details with Azure CLI queries and JSON output.
  • Assigned the Require a tag on resources policy at the rg-rbac-lab scope requiring Environment=Lab.
  • Deployed an Ubuntu VM with its network interface, NSG, virtual network and managed OS disk.
  • Created the Automation Account aa-rbaclab-shutdown with a system-assigned managed identity holding Virtual Machine Contributor at the VM scope.
  • Published the Shutdown-VM-Daily-UAE PowerShell runbook with three daily schedules (2:00 AM, 5:00 PM and 10:00 PM, Asia/Dubai).
