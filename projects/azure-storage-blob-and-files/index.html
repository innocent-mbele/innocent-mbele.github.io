Implement and Manage Azure Storage

I built storage for a finance team with a blob container and an Azure file share with a folder for each department.

Overview

I deployed a StorageV2 account in UAE North with Standard performance and locally redundant storage (LRS). I created a finance blob container and uploaded sample documents. Then I set up Azure Files with a finance-shared file share and folders for each finance department. I gave access with Azure RBAC and tested the file share from the Azure portal and from Windows over SMB.

What I set out to do

  • Store finance documents in Azure Blob Storage.
  • Give the finance departments a shared file share with their own folders.
  • Protect the data against accidental deletion.

What I did

  • I deployed the storage account innocentstorage07 in UAE North with Standard performance and LRS.
  • I created a finance blob container and uploaded sample documents.
  • I created the finance-shared file share with folders for Accounts Payable, Accounts Receivable, Financial Reports and Payroll.
  • I gave access through Azure RBAC.
  • I turned on blob soft delete, container soft delete and blob versioning.
  • I used Azure Monitor to look at storage transactions and availability.
