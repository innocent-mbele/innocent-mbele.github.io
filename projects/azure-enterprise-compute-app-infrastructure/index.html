Enterprise Compute and Application Infrastructure

Ubuntu Server 24.04 VM in Azure behind NAT Gateway and Azure Bastion, running a Flask portal on Gunicorn with PostgreSQL 16 in Docker Compose.

Overview

An Ubuntu Server 24.04 virtual machine was deployed in Azure to host an internal enterprise application environment. The application subnet and network security rules were configured, outbound connectivity was provided through an Azure NAT Gateway, and graphical access was enabled through Azure Bastion without a public IP on the VM. Docker Engine and Docker Compose were installed to run the application infrastructure in containers, PostgreSQL 16 was deployed as the database service, and the Enterprise Management Portal was built and deployed with Gunicorn as the application server.

Objectives

  • Host an internal application on a VM with no public IP address.
  • Provide controlled outbound connectivity and secure administrative access.
  • Run the database tier in containers and connect a Python web application to it.

What was done

  • Configured the application subnet and its network security group.
  • Deployed the Ubuntu Server 24.04 virtual machine and verified the operating system.
  • Allocated a Standard static public IP and deployed a NAT Gateway for the application subnet's outbound traffic.
  • Accessed the Ubuntu XFCE desktop through Azure Bastion.
  • Deployed PostgreSQL 16 with Docker Compose and created the dedicated enterprise_portal database and application account.
  • Deployed the Flask-based Enterprise Management Portal behind Gunicorn.

Testing and verification

  • Application health endpoint, PostgreSQL connectivity and the Gunicorn application server were verified.
  • The portal dashboard was opened in Firefox inside the VM at 127.0.0.1:8080.
  • Final NSG inbound rules reviewed: SSH access, internal HTTPS, Azure Bastion RDP access and an additional inbound restriction.
