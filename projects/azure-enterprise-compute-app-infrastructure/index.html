Enterprise Compute and Application Infrastructure

I set up an Ubuntu 24.04 server in Azure with no public IP. It reaches the internet through a NAT Gateway and I manage it through Azure Bastion. It runs a Flask web portal on Gunicorn with a PostgreSQL 16 database in Docker.

Overview

In this project I built a small internal business application environment in Azure. I deployed an Ubuntu Server 24.04 virtual machine without a public IP address. I configured the application subnet and its security rules, gave the subnet outbound internet access through an Azure NAT Gateway and used Azure Bastion to open the server desktop safely from the portal. On the server I installed Docker and Docker Compose, ran PostgreSQL 16 as the database and deployed my Enterprise Management Portal, a Flask application served by Gunicorn.

What I set out to do

  • Host an internal application on a server that has no public IP address.
  • Give the server controlled outbound access and safe admin access.
  • Run the database in containers and connect a Python web application to it.

What I did

  • I created the application subnet and its network security group.
  • I deployed the Ubuntu Server 24.04 virtual machine and checked the operating system.
  • I created a static public IP and a NAT Gateway for the subnet's outbound traffic.
  • I opened the Ubuntu desktop through Azure Bastion.
  • I deployed PostgreSQL 16 with Docker Compose and created the enterprise_portal database with its own application account.
  • I deployed the Flask portal behind Gunicorn.
