Linux Server Health Monitoring & Scheduled Reporting

Bash health-check script scheduled with Cron that checks memory, disk and services and returns a status exit code.

Overview

A Bash-based server health monitoring system was built that runs automatically with Cron and checks system resources and essential services.

Objectives

  • Automate routine server health checks and report a clear status.

What was done

  • Checked the Cron environment.
  • Ran the health-check script manually to produce a report.
  • Scheduled the script with Cron.

Screenshots

In the order they appear in the repository. Click one to see it full size.

Testing and verification

  • Cron executed the script automatically and generated the report.
  • Memory, disk and service checks returned OK with an overall healthy result.
  • A simulated failure was detected and returned a warning status.
  • The script returned exit code 0 when the system was healthy.
