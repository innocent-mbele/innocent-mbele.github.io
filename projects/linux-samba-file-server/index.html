Samba File Server

Authenticated SMB share on Ubuntu accessed from Linux and Windows clients.

Project overview

An Ubuntu server was configured as a Samba file server with an authenticated SMB shared folder, and file access was verified from a Windows client.

Objectives

  • Share files from Linux to Windows clients.

Implementation

  • Created the shared directory and the Shared share.
  • Validated the configuration with testparm.
