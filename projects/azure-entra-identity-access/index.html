Microsoft Entra ID Identity Management

I created a user and a security group in Microsoft Entra ID. Then I used the audit logs to see exactly who made each change and what changed.

Overview

Here I practised identity and access administration in Microsoft Entra ID. I reviewed the tenant settings, confirmed the Global Administrator role, created an internal user with its details and created a security group with an owner and a member. I then went through the sign-in logs and directory audit logs to follow the changes I had made.

What I set out to do

  • Create a user and a security group in Entra ID.
  • Use the audit logs to see who made each change and what changed.

What I did

  • I reviewed the Default Directory tenant and the Global Administrator role.
  • I created an internal user and filled in the user details.
  • I created the IT-Cloud-Ops security group with an owner and a member.
