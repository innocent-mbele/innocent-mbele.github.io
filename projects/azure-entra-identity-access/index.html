Microsoft Entra ID Identity Management

User and security group administration in Microsoft Entra ID, verified through directory audit logs.

Project overview

Identity and access administration was carried out in a Microsoft Entra ID tenant: inspecting the tenant configuration, verifying the Global Administrator role, creating an internal user with configured attributes and creating a security group with an assigned owner and member. Sign-in logs and directory audit logs were then reviewed to examine the provisioning and membership activity.

Objectives

  • Provision a user and a security group in Entra ID.
  • Use audit logs to verify who made each change and what changed.

Implementation

  • Reviewed the Default Directory tenant and the Global Administrator role assignment.
  • Created an internal user and configured user attributes.
  • Created the IT-Cloud-Ops security group with assigned membership, an owner and a member.
