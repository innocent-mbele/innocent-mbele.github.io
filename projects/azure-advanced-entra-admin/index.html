Advanced Microsoft Entra ID Administration

I reviewed device settings in Entra ID and created seven users in bulk. I then used Microsoft Graph PowerShell to check the accounts, export them to CSV and add them to a group.

Overview

In this project I went deeper into Microsoft Entra ID administration. I reviewed the device join, local administrator and device security settings. I created seven users with the bulk create feature. The portal did not clearly confirm whether the CSV upload had worked, so I followed Microsoft's guidance and used Microsoft Graph PowerShell to check the accounts, export their details and add them to a security group.

What I set out to do

  • Review device join, local admin and device security settings.
  • Create users in bulk and confirm the result myself.
  • Automate group membership with Microsoft Graph PowerShell.

What I did

  • I reviewed device join and registration, local administrator, LAPS and BitLocker recovery settings.
  • I created seven internal users with bulk user creation.
  • I connected to Microsoft Graph and listed the seven accounts.
  • I exported their profile details to CSV.
  • I created the IT-Cloud-Ops-Automation security group with Graph PowerShell and added all seven users.

How I tested it

  • Graph PowerShell listed the seven users with their UPNs, departments and job titles.
  • I imported the exported CSV back into PowerShell to check the records.
  • I listed the group members separately to confirm all seven were added.

Problems I hit

  • The portal did not clearly show the result of the CSV bulk upload. I moved the checking to Microsoft Graph PowerShell instead.
