Advanced Microsoft Entra ID Administration

Device settings review, bulk user creation and Microsoft Graph PowerShell automation of user verification, CSV export and group membership.

Project overview

Device join, registration and security settings were inspected in a Microsoft Entra ID tenant. Seven internal users were created with the bulk user creation feature. Because the portal did not clearly confirm the CSV bulk operation's results, Microsoft Graph PowerShell was used, following Microsoft's documentation on bulk operation service limitations, to verify the accounts, export their profiles and automate group membership.

Objectives

  • Review device join, local administrator and device security settings.
  • Provision users in bulk and verify the outcome independently.
  • Automate group membership with Microsoft Graph PowerShell.

Implementation

  • Reviewed device join and registration settings, local administrator settings and LAPS / BitLocker recovery settings.
  • Created seven internal users with Entra ID bulk user creation.
  • Established a delegated Microsoft Graph connection and retrieved the seven accounts.
  • Exported user profile information to CSV.
  • Created the IT-Cloud-Ops-Automation security group with Graph PowerShell and added all seven users.

Testing and verification

  • The seven users were retrieved with Graph PowerShell, showing UPNs, departments and job titles.
  • The exported CSV was imported back into PowerShell to confirm the records.
  • Group membership was independently retrieved to confirm all seven users were added.

Results and observations

  • Problem: the portal did not give clear confirmation of the CSV bulk operation results. Fix: verification was moved to Microsoft Graph PowerShell.
