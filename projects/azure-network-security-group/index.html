Azure Network Security Group

NSG with SSH and HTTP inbound rules associated with a VNet subnet.

Overview

An Azure Network Security Group was created to control inbound traffic, with rules allowing SSH (port 22) for administration and HTTP (port 80) for web traffic, and was associated with the virtual network subnet.

Objectives

  • Filter inbound traffic to a subnet.

What was done

  • Created the NSG and reviewed its default inbound and outbound rules.
  • Added inbound rules for SSH (22) and HTTP (80).
  • Associated the NSG with the subnet.
