Azure Network Security Group

I created a network security group that allows SSH and HTTP and attached it to my subnet.

Overview

I created an Azure network security group to control incoming traffic. I added rules that allow SSH on port 22 for administration and HTTP on port 80 for web traffic, then attached the group to my subnet.

What I set out to do

  • Control which traffic can reach the subnet.

What I did

  • I created the NSG and looked through its default rules.
  • I added inbound rules for SSH on port 22 and HTTP on port 80.
  • I attached the NSG to the subnet.
