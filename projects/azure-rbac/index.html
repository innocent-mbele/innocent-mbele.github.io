Azure Role-Based Access Control (RBAC)

I gave users only the access they need at resource group level. I also created a custom role that can start and restart VMs but cannot delete them.

Overview

Here I practised role-based access control in Azure. I reviewed the roles and permissions on my subscription, created a resource group and assigned roles at that level. I gave different users the built-in Reader and Virtual Machine Contributor roles. I then created my own role called VM Operator - Limited and assigned it to a test user.

What I set out to do

  • Give least-privilege access at resource group level.
  • Create a custom role that limits what a user can do with VMs.

What I did

  • I reviewed the Owner role I inherit from the subscription and the built-in role permissions.
  • I assigned Reader and Virtual Machine Contributor on rg-rbac-lab.
  • I created VM Operator - Limited. It can view, start and restart VMs but cannot delete VMs or assign roles.
  • I assigned the custom role to a lab user on the resource group.
