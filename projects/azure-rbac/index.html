Azure Role-Based Access Control (RBAC)

Built-in role assignments at resource-group scope and a custom VM Operator - Limited role that can start and restart but not delete VMs.

Project overview

Role definitions and subscription-level permissions were reviewed, a resource group was created and role assignments were configured at resource-group scope. Built-in Reader and Virtual Machine Contributor roles were assigned to different users, and a custom role named VM Operator - Limited was created and assigned.

Objectives

  • Apply least-privilege access at resource-group scope.
  • Create a custom role that limits VM operations.

Implementation

  • Reviewed the Owner role assignment inherited at subscription scope and built-in role permissions.
  • Assigned Reader and Virtual Machine Contributor at the rg-rbac-lab scope.
  • Created VM Operator - Limited, allowing users to view, start and restart VMs without permission to delete VMs or assign roles.
  • Assigned the custom role to a lab user at the resource-group scope.
