Azure Managed Disks

Managed data disk attached to an Ubuntu VM, then partitioned, formatted and mounted.

Overview

An Azure Managed Disk was created and attached to an existing Ubuntu VM, then partitioned, formatted and mounted to provide additional persistent storage.

Objectives

  • Add persistent storage to a running VM.

What was done

  • Attached a managed data disk to the VM.
  • Partitioned, formatted and mounted it over SSH.
