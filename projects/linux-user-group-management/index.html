User & Group Management

I created department groups and users and controlled folder access with chown, chmod, SGID and the sticky bit.

Overview

I created department groups and user accounts, added the users to their groups and controlled folder access with chown, chmod, SGID and the sticky bit.

What I set out to do

  • Make sure each user can only reach the folders they should.

What I did

  • I created the groups and users and set their memberships.
  • I set owners and permissions on the department folders.
  • I applied SGID and the sticky bit.

Screenshots

They are in the same order as in my repository. Click one to see it full size.

How I tested it

  • New files took the folder's group because of SGID.
  • Users could not delete each other's files in the sticky bit folder.
