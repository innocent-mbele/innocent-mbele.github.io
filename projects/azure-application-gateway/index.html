Azure Application Gateway

Layer 7 load balancing of HTTP traffic across two Nginx VMs with an Azure Application Gateway, shown in a demo video.

Project overview

An Azure Application Gateway was deployed to distribute HTTP traffic across two Linux virtual machines running Nginx. The work covered the dedicated subnet, frontend configuration, backend pool, listener, backend settings, routing rules, validation, deployment and end-to-end verification.

Objectives

  • Deploy Layer 7 load balancing in front of two web servers.

Architecture and design

Diagram reproduced from the project README.

Implementation

  • Created a dedicated Application Gateway subnet.
  • Configured the frontend public IP.
  • Added both Linux VMs to the backend pool.
  • Configured the HTTP listener, backend settings and routing rule.
  • Validated and deployed the gateway.
