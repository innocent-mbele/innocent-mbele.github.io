Azure Application Gateway

I put an Azure Application Gateway in front of two Nginx web servers so that traffic is shared between them. I recorded a short video of it working.

Overview

In this project I deployed an Azure Application Gateway to share web traffic between two Linux virtual machines running Nginx. I created the gateway's own subnet and set up the frontend, backend pool, listener, backend settings and routing rule. After Azure validated the settings I deployed it and tested it from the browser.

What I set out to do

  • Share HTTP traffic between two web servers at layer 7.

What I did

  • I created a dedicated subnet for the gateway.
  • I set up the frontend public IP.
  • I added both Linux VMs to the backend pool.
  • I configured the HTTP listener, backend settings and routing rule.
  • I validated and deployed the gateway.
