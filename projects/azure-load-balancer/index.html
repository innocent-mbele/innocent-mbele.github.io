Azure Standard Load Balancer

I set up an Azure Standard Load Balancer with a health probe to share web traffic between two Ubuntu servers running Nginx.

Overview

Here I deployed an Azure Standard Load Balancer in front of two Ubuntu virtual machines running Nginx. I configured the frontend public IP, the backend pool, an HTTP health probe and the load balancing rule.

What I set out to do

  • Share web traffic between two servers and stop sending traffic to a server that is down.

This diagram comes from my project README.

What I did

  • I deployed the Standard Load Balancer with a frontend public IP.
  • I added both Ubuntu VMs to the backend pool.
  • I created an HTTP health probe and a load balancing rule.
  • I installed Nginx on both VMs.

How I tested it

  • The health probe showed both servers as healthy.
  • Repeated curl requests from PowerShell were answered by both VMs.
  • In the browser I saw pages from vm-cloud-labs-linux-001 and vm-cloud-labs-linux-002.
