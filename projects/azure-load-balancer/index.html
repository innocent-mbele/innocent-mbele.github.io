Azure Standard Load Balancer

Standard Load Balancer with health probe and HTTP rule distributing traffic across two Ubuntu VMs running Nginx.

Project overview

An Azure Standard Load Balancer was deployed to distribute HTTP traffic across two Ubuntu Linux virtual machines running Nginx, with a frontend public IP, backend pool, HTTP health probe and load-balancing rule.

Objectives

  • Distribute HTTP traffic across two VMs and remove unhealthy instances automatically.

Diagram reproduced from the project README.

Implementation

  • Deployed the Standard Load Balancer with a frontend public IP.
  • Added both Ubuntu VMs to the backend pool.
  • Created an HTTP health probe and a load-balancing rule.
  • Installed Nginx on both VMs.

Testing and verification

  • Both backend VMs reported healthy in the health probe status.
  • PowerShell curl requests were distributed between both VMs.
  • The browser showed pages served by vm-cloud-labs-linux-001 and vm-cloud-labs-linux-002.
