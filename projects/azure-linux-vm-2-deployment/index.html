Azure Linux VM 2 Deployment

Second Ubuntu VM with SSH keys, NSG protection and Nginx, later used as a load-balancer backend.

Overview

A second Ubuntu Linux VM was deployed in Azure with SSH key authentication, secured with a Network Security Group and prepared to host web applications with Nginx.

Objectives

  • Provide a second web server for load-balancing labs.

What was done

  • Reviewed and deployed the VM.
  • Connected over SSH with key-based authentication.
  • Installed Nginx.
