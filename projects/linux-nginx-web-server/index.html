Nginx Web Server

I installed Nginx on Ubuntu, set up my own site and checked the access and error logs.

Overview

I installed Nginx on Ubuntu, created my own HTML page and site configuration, enabled the site and then went through the access and error logs.

What I set out to do

  • Serve my own site with Nginx and open it from another machine.

What I did

  • I installed Nginx and confirmed it was listening on port 80.
  • I created my page and site configuration in sites-enabled.
  • I tested the configuration and reloaded Nginx.

Screenshots

They are in the same order as in my repository. Click one to see it full size.

How I tested it

  • curl returned the page on the server.
  • A browser on the network opened my page by IP address.
  • The access and error logs recorded the requests.
