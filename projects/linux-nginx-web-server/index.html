Nginx Web Server

Nginx install, custom site configuration, config testing and log review on Ubuntu.

Project overview

Nginx was installed on Ubuntu, a custom HTML page and site configuration were created and enabled, and access and error logs were reviewed.

Objectives

  • Serve a custom site with Nginx and confirm it from a client.

Implementation

  • Installed Nginx and confirmed it listened on TCP 80.
  • Created a custom page and site configuration in sites-enabled.
  • Tested the configuration syntax and reloaded Nginx.
