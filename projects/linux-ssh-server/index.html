SSH Server Configuration

I moved OpenSSH to port 2222 and connected to it from Windows.

Overview

I installed OpenSSH Server on Ubuntu and changed sshd_config so the service listens on a different port.

What I set out to do

What I did

  • I installed OpenSSH Server.
  • I changed the port from 22 to 2222 in sshd_config.
